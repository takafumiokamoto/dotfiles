# 英文添削

引数: `$ARGUMENTS`

引数が英文ならそれを、ファイルパスならそのファイルを読んで対象にする。空なら会話中の英文を対象にする。

## 方針

- 誤りと、ネイティブが使わない不自然な表現だけを直す。
- 解説は日本語で書く。

## 出力

````markdown
## 修正版

```
（貼り付けて使える全文）
```

## 修正点

| 原文 | 修正後 | 種類 | 理由 |
| ---- | ------ | ---- | ---- |
````

## ファイルが引数のとき

- ファイルは編集しない。修正版の全文は出さず、修正点の表の先頭に「場所」列（`パス:行番号`）を加えて返す。
- 反映を頼まれたら直接編集する。意図が二通りに読める箇所は編集せず、案を示す。
